# 比赛信息汇总

## 一、嵌入式芯片与系统设计竞赛（嵌赛）

### 基本信息
- **全称**: 第九届(2026)全国大学生嵌入式芯片与系统设计竞赛·芯片应用赛道
- **主办**: 中国电子教育学会
- **口号**: AI赋能设计，设计点亮AI! (AI for Design & Design for AI!)
- **官网**: https://www.socchina.net

### 时间节点
| 事项 | 日期 |
|------|------|
| 报名截止 | 2026-04-20 |
| 作品提交截止 | 2026年7月上旬 |
| 初赛/复赛 | 2026年7月 |
| 全国总决赛 | 2026年8月 |

### 参赛要求
- 1-3人/队 + 不超过2名指导老师
- 分研究生组、本科组、高职高专组
- 报名网站: www.socchina.net

### 乐鑫赛题要求
- **选题**: 选题五 — 智能交互驱动的AIoT应用系统
- **主控**: 必须用 ESP32-P4 或 ESP32-S3（我们选S3）
- **自制PCB**: 必须丝印 "AI for Design, Design for AI" + 加工时间
- **禁止**: 不得出现学校、老师、学生姓名
- **核心功能**: 必须运行在ESP芯片上，不能只当通信模块

### 评审标准
- 完成度、创新性、难度
- 系统功能与指标
- 答辩表现
- **总决赛增加能力测评**（乐鑫赛题为书面考核1小时）

### 奖项
- 赛区：一等奖(≤20%), 二等奖(≤25%), 三等奖
- 全国：一等奖(≤15%), 二等奖(≤30%), 三等奖
- 乐鑫额外：实习机会、校招绿色通道、500元开发套件

### 乐鑫资源
- 赛题页面: https://www.espressif.com/zh-hans/ecosystem/education/competition/socchina
- 代金券返还: 买开发板提交有效作品后返99元
- 云端大模型额度: 火山引擎200w token + 百度飞桨100w token
- QQ答疑群（见赛题指南）

- **主办**: 全国高等学校计算机教育研究会
- **官网**: http://iot.sjtu.edu.cn
- **组委会**: 上海交通大学

### 时间节点
| 事项 | 日期 |
|------|------|
| 报名开始 | 2026-04-01 |
| 报名截止 | 2026-06-15 |
| 作品方案提交开始 | 2026-05-15 |
| 作品提交截止 | 2026-07-27 |
| 分赛区网评 | 2026-08-10前 |
| 分赛区决赛 | 2026-08-20前 |
| 全国总决赛 | 2026-08-20 ~ 08-31 |

### 参赛要求
- ≤4人/队 + ≤2名指导老师
- 同校组队，不可跨校
- 作品须为学生原创
- 竞赛网站注册: iot.sjtu.edu.cn

- **可选芯片**: ESP32-S3, ESP32-C5, ESP32-P4 (三选一)
- 开发套件免费申领（限量）

### 评审

### 乐鑫资源

## 三、一个作品打两个赛的策略

### 共同要求
| 项目 | 嵌赛 | 物联网赛 | 我们的方案 |
|------|------|----------|-----------|
| 主控 | ESP32-S3 or P4 | ESP32-S3/C5/P4 | ESP32-S3 |
| 自制PCB | 必须 | 不要求 | 做（嵌赛需要） |
| AI能力 | 强烈鼓励 | 加分项 | 小智AI语音 |
| 物联网 | 不硬性 | 核心要求 | WiFi+云端大模型 |
| 开源 | 鼓励 | 鼓励 | GitHub开源 |

### 侧重点调整
- **嵌赛提交**: 强调自制PCB、AI边缘计算、系统完整性、硬件设计能力
- **物联网赛提交**: 强调物联网连接、云端交互、实际应用价值、演示效果

### 文档准备
两个比赛需要分别准备：
1. 设计报告（格式不同）
2. 演示视频
3. 作品实物演示
